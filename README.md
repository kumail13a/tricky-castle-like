# Racepord castel
لعبة منصّات ألغاز بفخاخ مخفية (HTML5 Canvas) + تغليف أندرويد بـ Capacitor.

## التشغيل على المتصفح
افتح `www/index.html`. التحكم: الأسهم / WASD / مسافة، أو أزرار الشاشة.

## الحصول على APK
ارفع المشروع إلى GitHub، وسيبني `GitHub Actions` ملف APK تلقائياً:
Actions ← آخر تشغيل "Build APK" ← Artifacts ← `tricky-castle-apk`.

## مفتاح الخرائط (`www/game.js`)
`#` جدار · `F` أرضية وهمية · `^` شوكة · `H` شوكة مخفية · `C` كتلة ساقطة · `W` منشار دوّار · `X` باب مزيّف قاتل · `K` مفتاح · `D` باب · `P` بداية

## التحديث الهوائي (OTA)
1. في `www/config.js` استبدل `USERNAME` باسم حسابك على GitHub (واسم المستودع إن اختلف).
2. في GitHub: Settings ← Pages ← Source: **GitHub Actions**.
3. لإصدار تحديث: عدّل `www/game.js` (مراحل، فخاخ...)، ارفع رقم `version` في `www/version.json`، ثم `git push`.
4. عند فتح اللعبة التالية على الجوال (مع إنترنت) تُحمَّل النسخة الجديدة وتعيد التشغيل تلقائياً.

ملاحظة: التحديث الهوائي يغطي ملفات الويب فقط (الكود والمراحل). أي تغيير في الأندرويد نفسه (اسم التطبيق، الأيقونة، الصلاحيات) يحتاج APK جديداً.
